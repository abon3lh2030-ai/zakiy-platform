# موقع ذكيّ - بنية الملفات

الموقع يُنشر على GitHub Pages كملف `index.html` واحد ثابت (بدون أي خطوة
بناء من عندهم). عشان نقدر نطوّر ونعدّل بملفات صغيرة منظمة بدل ملف واحد
ضخم، الكود الفعلي مقسّم بمجلد `src/`، وفيه سكربت `build.py` يجمعهم
بملف `index.html` النهائي قبل كل رفع.

## القاعدة الذهبية

**لا تعدّل `index.html` مباشرة.** أي تعديل لازم يصير بملفات `src/`، بعدين
تشغّل:

```bash
python3 website/build.py
```

هذا يعيد توليد `website/index.html` من جديد. بعد التوليد، انسخه لنسخة
الجذر (يُخدم منها الموقع فعليًا عبر GitHub Pages):

```bash
cp website/index.html index.html
```

## بنية src/

```
src/
  head.html              رأس الصفحة (قبل <style>) - meta, title, خطوط, روابط CDN
  css/                   كل تنسيقات الموقع، مقسّمة بملف لكل قسم (00-base.css
                         أساسيات عامة، ثم ملف بكل ميزة: 19-sidebar.css،
                         31-notes.css، 33-ai-assistant.css...)
  js/                    كل منطق الموقع، مقسّم بملف لكل ميزة (00-globals.js
                         متغيرات عامة، 01-i18n.js الترجمة، 08-library.js
                         المكتبة، 23-notes.js الملاحظات، 25-ai-assistant.js
                         المساعد الذكي...)
  pages/                 كل "شاشة" بملف HTML لحالها، مرتبة بمجلدات حسب الميزة:
    auth/                تسجيل الدخول، إنشاء حساب، تغيير كلمة سر إجباري
    home/                الواجهة الرئيسية (اختيار الوضع، الغرف، رفع/تلخيص/اختبار)
    settings/             الإعدادات + نافذة الدفع
    notes/               دفتر الملاحظات (قائمة + محرر)
    assignments/         دفتر الواجبات (قائمة + تفاصيل)
    ai-assistant/        المساعد الذكي (محادثات + محادثة + اختيار كتاب)
    library/             المكتبة الشخصية
    social/              الأصدقاء، الأرشيف، الأداء، الرسائل، البروفايل
    school-system/       لوحات الأدمن/المدرسة/المعلم/جدول الطالب
    partials/            عناصر مشتركة تظهر بكل الصفحات (السايد بار، مودالات عامة)
  manifest.json          الترتيب الدقيق لكل ملفات pages/ داخل <div class="wrap">
                         (المصدر الوحيد للترتيب - build.py يمشي عليه بالظبط)
```

## ليش فيه manifest.json؟

كل "صفحات" الموقع (الشاشات) تعيش فعليًا جوا عنصر واحد `<div class="wrap">`
بالصفحة الأصلية، وترتيبها بينها مهم (نفس ترتيب ظهورها بالمستند الأصلي).
بدل ما نشفّر هذا الترتيب جوا `build.py` نفسه، حطيناه بملف JSON منفصل
سهل القراءة والتعديل - أي صفحة جديدة تضيفها لازم تسجّلها بـ manifest.json
بمكانها الصح.

## إضافة صفحة/ميزة جديدة

1. أنشئ ملف HTML جديد جوا `pages/<القسم المناسب>/اسم-الصفحة.html`
   (المحتوى نفسه بس، من غير أي `<script>`/`<style>` جواه).
2. سجّله بـ `manifest.json` بالمكان الصح (بالترتيب اللي تبيه يظهر فيه
   بالصفحة).
3. لو له تنسيقات خاصة: أنشئ `css/XX-اسم-الميزة.css` وسجّله بقائمة
   `CSS_ORDER` جوا `build.py`.
4. لو له منطق JS خاص: أنشئ `js/XX-اسم-الميزة.js` وسجّله بقائمة
   `JS_ORDER` جوا `build.py`.
5. شغّل `python3 website/build.py` وتأكد الموقع يشتغل صح محليًا قبل الرفع.
