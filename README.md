# ذكيّ (Zakiy) 🧠

**منصة تعليمية رقمية ذكية مدعومة بالذكاء الاصطناعي**

[zakiy.tech](https://zakiy.tech)

ذكيّ هو نظام تعليمي متكامل يهدف إلى تطوير تجربة التعلّم والمذاكرة للطلاب، وتمكين المعلمين والمدارس من إدارة العملية التعليمية من مكان واحد.

تجمع المنصة بين أدوات الذكاء الاصطناعي، إدارة المحتوى التعليمي، الاختبارات، التحليلات، المذاكرة الجماعية، الفصول الافتراضية، والمختبرات التفاعلية ضمن تجربة عربية حديثة وسهلة الاستخدام.

# 🏗️ هيكل المشروع

الهيكل الأساسي للمشروع:

```text
zakiy-platform/
├── backend/
│   ├── app.py
│   ├── requirements.txt
│   ├── .env
│   └── ...
│
├── index.html
└── README.md
- backend/ يحتوي على منطق الخادم والـ APIs والتكاملات الخلفية.
- index.html يحتوي على واجهة المنصة الرئيسية.
- المتغيرات السرية ومفاتيح الخدمات تحفظ في .env ولا يتم رفعها إلى المستودع.
⚙️ التشغيل المحلي
1. استنساخ المشروع
git clone <repository-url>
cd zakiy-platform
2. تجهيز الـ Backend
cd backend

python3 -m venv venv
source venv/bin/activate
على Windows:
venv\Scripts\activate
ثم تثبيت المتطلبات:
pip install -r requirements.txt
3. إعداد متغيرات البيئة
أنشئ ملف:
backend/.env
وأضف مفاتيح الخدمات التي يحتاجها المشروع.
مثال:
GEMINI_API_KEY=your_api_key
لا تقم برفع ملف .env أو أي مفاتيح سرية إلى GitHub.

4. تشغيل الـ Backend
من داخل مجلد backend:
python app.py
5. تشغيل الواجهة
ارجع إلى مجلد المشروع الرئيسي:
cd ..
ثم شغّل index.html باستخدام خادم محلي مثل Live Server، أو بالطريقة المناسبة لبيئة التطوير لديك.
🧩 البنية العامة
يعتمد ذكيّ على فصل الواجهة عن منطق الخادم:
المستخدم
   ↓
واجهة ذكيّ
   ↓
Backend API
   ↓
الخدمات الداخلية والخارجية
   ↓
الذكاء الاصطناعي / معالجة الملفات / الخدمات التعليمية
🔐 الأمان
عند تطوير أو تشغيل المنصة:
- لا تضع مفاتيح API داخل الواجهة مباشرة.
- لا ترفع ملف .env إلى Git.
- احتفظ بالمفاتيح السرية داخل الـ Backend.
- تحقق من البيانات القادمة من المستخدم.
- استخدم HTTPS في بيئة الإنتاج.
- لا تخزن بيانات حساسة إلا عند الحاجة وبطريقة آمنة.
