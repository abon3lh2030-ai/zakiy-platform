# ذكيّ (Zakiy) — منصة المذاكرة الذكية

مشروع تخرج — أكاديمية طويق (مسار المهندسين)

## هيكل المشروع
```
zakiy-platform/
├── backend/
│   ├── app.py              # سيرفر Flask + كل الـ endpoints
│   ├── requirements.txt    # المكتبات المطلوبة
│   └── .env.example        # مثال لملف المفاتيح
└── frontend/
    └── index.html          # الواجهة كاملة (HTML+CSS+JS بملف واحد)
```

## خطوات التشغيل

### 1) تجهيز الـ Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate      # ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### 2) إضافة مفتاح الذكاء الاصطناعي
سوّي ملف اسمه `.env` جوا مجلد `backend` (انسخ من `.env.example`) وحط فيه مفتاحك:
```
GEMINI_API_KEY=مفتاحك_الحقيقي
```
تقدر تحصل على مفتاح مجاني من: https://aistudio.google.com/apikey

### 3) تشغيل السيرفر
```bash
python app.py
```
السيرفر بيشتغل على: `http://127.0.0.1:5001`

### 4) تشغيل الواجهة
افتح ملف `frontend/index.html` مباشرة بالمتصفح (دبل كلك عليه)، أو استخدم إضافة Live Server بـ VS Code.

⚠️ **مهم:** لازم الـ Backend يكون شغال قبل ما تفتح الواجهة، وإلا بتطلع أخطاء اتصال.

## الـ Endpoints المتوفرة
| Endpoint | الوظيفة |
|---|---|
| `GET /api/health` | فحص إن السيرفر شغال |
| `POST /api/upload` | رفع ملف PDF |
| `POST /api/extract` | استخراج النص من الملف المرفوع |
| `POST /api/summarize` | تلخيص النص بالذكاء الاصطناعي |
| `POST /api/generate-quiz` | توليد اختبار اختيار من متعدد من النص |
| `POST /api/room/create` | إنشاء غرفة مذاكرة جماعية من اختبار جاهز |

## غرفة المذاكرة الجماعية (Real-time)
بعد توليد الاختبار، أي طالب يقدر يحوّله لغرفة مذاكرة جماعية بالضغط على "🎓 حوّل لغرفة مذاكرة جماعية"،
فيحصل على كود غرفة قصير يشاركه مع زملائه. أي طالب ثاني يدخل الكود واسمه من بطاقة "غرفة موجودة" بأعلى
الصفحة، ويحل نفس الاختبار. لوحة الصدارة تتحدث لحظيًا لكل المشاركين (عبر WebSockets — Flask-SocketIO)
كل ما أحد يخلّص ويتحقق من نتيجته. الغرف مخزّنة بالذاكرة فقط (بدون قاعدة بيانات)، فتختفي إذا أعدت تشغيل السيرفر.

## الخطوات القادمة (مو مبنية بعد)
- تسجيل دخول وحسابات للطلاب
- لوحة تحليل نقاط الضعف بعد الاختبارات
- حفظ الغرف بقاعدة بيانات بدل الذاكرة (عشان تنجو من إعادة تشغيل السيرفر)
